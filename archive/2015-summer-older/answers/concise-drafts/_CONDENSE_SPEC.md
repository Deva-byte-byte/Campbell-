# Condensing spec (half-length exam answers)

Goal: the candidate reads too slowly for the full set. Produce a version ~HALF the length (or a little less), keeping everything an examiner expects and dropping what nobody expects a candidate to know or write.

## Hard rules
1. **No new facts.** Only shorten/rephrase what is already in the source file. Do not add any number, trial, drug, date, name or claim that is not in the source. Do not change any number.
2. Keep every examinable core item: definitions, classifications/grading tables, key cut-offs and doses, management steps/algorithms, indications/contraindications, main complications, the 1–3 landmark trials per topic, current guideline position.
3. **Drop** low-yield detail: extra history dates, long lists of rare causes/associations, secondary/minor trials, minor device/brand names, molecular minutiae, "Sources: Campbell chapter…" lines, hedging asides, repeated explanations, filler words.
4. Telegraphic note style: "Volume ↓20–25%", "→", "↑/↓", abbreviations already defined in the answer. No full sentences where a phrase works. Prefer tables for comparisons/classifications.
5. Recent advances: keep only the 2–3 most examinable bullets.
6. "Diagram to draw": keep one short line.
7. Key points box: keep it at the end of each answer, 3–4 one-line bullets, in exactly this form:
   > **Key points to remember:**
   > - ...
8. Keep flowcharts (fenced code blocks) for management algorithms but make them short.

## Word budgets (body, excluding key points box)
- LAQ (25 marks): 600–750 words
- SAQ (10 marks): 230–300 words
- Paper IV Q3c (SNM cross-reference): keep as a short cross-reference (≤60 words)

## Format (unchanged structure)
- File starts with `# Paper ... ` heading and short contents list (plain numbered list, no links needed).
- Each question: `## <id>. <question text exactly as in source>` then `**Type:** LAQ (25 marks)` or `**Type:** SAQ (10 marks)`, then `###` sub-headings, bullets, tables, key points box. Separate questions with `---`.
- Do NOT include the "Rapid Revision Sheet" section from the source (it is regenerated automatically).

## Acronyms (user requirement)
- Spell out every acronym in full at its first use in EACH answer, e.g. "GFR (glomerular filtration rate)", then use the acronym afterwards. Common units (mL, mg, mmHg, Fr, °C) need no expansion.

## Revision 2 (user feedback: telegraphic bullets are hard to understand)
1. **Readability first**: wherever a bullet is cryptic (symbol strings, chains of arrows, slashes, missing verbs), rewrite it as a short, clear sentence or sentence-fragment that reads naturally, e.g. "AUR/surgery ↓ ~50%" → "Reduces the risk of AUR and surgery by about 50%." Keep simple arrows only where they genuinely read well (e.g. in flowcharts or cause → effect).
2. **Restore the major subheadings** of each answer from the full version (answers/full/...). Every standard exam heading that existed there (e.g. Definition, Classification, Pathophysiology, Clinical features, Evaluation/Investigations, Management, Complications, Follow-up, Recent advances, Diagram) should be present again, each with at least 1–2 bullets of the most exam-relevant content. Merged headings may stay merged only if both names appear in the heading.
3. Keep only exam-oriented content: what a candidate would write and an examiner would mark. Drop trivia to pay for the extra words.
4. Word budgets (body, excluding key points box): LAQ 650–800, SAQ 260–330. Overall paper ≈3,300–3,500 words whole-file.
5. All earlier rules still apply: NO new facts or numbers beyond the full source, no number changes, acronyms expanded at first use in each answer, key points box kept at the end of each answer.
