# Style spec for MCh Urology model answers (shared by all writers)

Audience: an Indian MCh Urology candidate revising the night before. Exam = 3 h, 2 LAQ x 25 marks + 5 SAQ x 10 marks. They must READ everything in <=5 h total, so respect word budgets.

## Sources (priority order)
1. Campbell-Walsh-Wein Urology (latest edition) - primary. Name the relevant Campbell chapter topic (e.g. "Campbell: Ureteroscopy chapter"). Do NOT invent page numbers or edition-specific chapter numbers.
2. Guidelines: EAU (2024/2025), AUA, NCCN, AUA/SMSNA, KDIGO, Indian THOA where relevant. Give guideline name + year only when sure.
3. Landmark trials/studies: name, year, one-line result. Only cite trials you are certain exist with correct results.

## ACCURACY RULES (most important)
- Every number (doses, cut-offs, percentages, sizes, dates, names) must be correct. If unsure of an exact figure, give the well-established range or omit it - NEVER fabricate.
- No made-up trials, authors, years, devices.
- Where sources disagree, state both briefly ("EAU: ...; AUA: ...").
- Prefer the current standard; mention withdrawn/obsolete items as such (e.g. UroLume withdrawn).

## Format (Markdown)
For each question:

```
## <Paper>-<Q no>. <Question text exactly as in paper>
**Type:** LAQ (25 marks) | ~1500 words   (or SAQ (10 marks) | ~550 words)

### Introduction / Definition
- ...
### <logical headings>
- bullets, sub-bullets
| tables where they compress info |
```
- Use ASCII flowcharts in fenced code blocks for algorithms.
- Add a line "**Diagram to draw:** ..." describing 1-2 simple labelled diagrams worth drawing in the exam.
- Include "### Recent advances" for every question where relevant (newest devices/drugs/trials up to 2025).
- End each answer with "> **Key points to remember:** ..." (3-5 crisp one-liners: numbers, eponyms, trials).
- Bullet points throughout - no long paragraphs.
- Word budget: LAQ 1300-1700 words; SAQ 450-650 words. Do not exceed.
- Separate questions with a horizontal rule `---`.

## LAQ skeleton
Intro/definition -> relevant anatomy/physiology -> aetiology/pathophysiology -> classification -> clinical features -> evaluation -> management (stepwise, indications, technique steps, outcomes) -> complications -> follow-up -> recent advances -> key points.

## SAQ skeleton
Definition -> key classification/mechanism -> evaluation (if relevant) -> management/table -> recent advances -> key points.
