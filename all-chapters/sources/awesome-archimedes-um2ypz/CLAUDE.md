# Campbell-Walsh-Wein chapter notes

The standing instructions for this repository are in
[`INSTRUCTIONS.md`](INSTRUCTIONS.md). Read the whole file at the start of
every session and follow it for every chapter pasted.

- Compiled PDFs go in `notes/Chapter NN — Title/`.
- Rendering: WeasyPrint with Carlito (`pip install weasyprint`;
  `apt-get install fonts-crosextra-carlito`). Greyscale page checks can be
  rasterised with `pypdfium2`.
