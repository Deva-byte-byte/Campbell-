# Campbell-Walsh-Wein Chapter Notes — project memory

The standing instructions for this project live in `INSTRUCTIONS.md`. Follow them in every session:
summarise pasted instalments live, then on "compile" produce the two A4 black-and-white PDFs
(Document 1 cheat sheet, Document 2 chapter notes) with WeasyPrint and Carlito.

## Environment setup (cloud containers start without these)

    pip install weasyprint
    apt-get install -y fonts-crosextra-carlito   # run apt-get update first if needed

Never use wkhtmltopdf.
