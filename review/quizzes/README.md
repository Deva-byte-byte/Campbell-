# Finished MCQ quizzes

Each `.html` file is a complete, self-contained quiz (open it in a browser). Each matching `.json` file holds the same questions as data: `q` stem, `o` options, `a` index of the correct option (0 = A), `e` explanation, `b` key-point bullets (newer sets), `s` source chapter.

| Folder | Contents |
|---|---|
| `general-urology-ch01-19/` | General urology, chapters 1–19 (evaluation, surgical basics, endourology/laparoscopy) |
| `sets-of-20/` | The 20-set series covering every fact of chapters 20–162 (done: 1–7, 20). Source files: `../sets/setNN.py` |
| `chapter-quizzes/` | Earlier chapter-block quizzes (paediatrics, infection, STI/skin, TB/genetics, testis/penile tumours, adrenal/pelvis, prostate) |
| `old-41-plan/` | Two sets from the abandoned 41-set plan (include chapter 16 haematuria) |
| `other/` | Early drills and prize rounds |
