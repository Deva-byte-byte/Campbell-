Chapter-by-chapter revision notes for *Campbell-Walsh-Wein Urology*, written
to the standing instructions in [`INSTRUCTIONS.md`](INSTRUCTIONS.md).

Each compiled chapter produces two A4, black-and-white PDFs:

1. `Chapter NN — Title — Numbers, Gold Standards and Traps.pdf`: a two-sided cheat sheet.
2. `Chapter NN — Title — Chapter Notes.pdf`: the full study notes.
