# Campbell-Walsh-Wein chapter notes

Standing instructions for every session in this repository live in
`INSTRUCTIONS.md`. Read and follow them in full before summarising any pasted
chapter material or compiling any chapter.

Toolchain for compilation: WeasyPrint (never wkhtmltopdf), Carlito font
(`fonts-crosextra-carlito`, DejaVu Sans fallback), PyMuPDF (`pip install pymupdf`)
for greyscale rasterisation checks. Install with
`pip install weasyprint && apt-get install -y fonts-crosextra-carlito && pip install pymupdf`
if missing.
